# 面向普通话声调学习的可解释 AI 反馈系统

## 摘要

普通话声调学习不仅要求学习者判断阴平、阳平、上声、去声四个调类，还要求其在产出中控制可测量的音高轮廓。传统自动发音评价容易把反馈压缩成分数或类别，难以说明学习者的音高运动为什么偏离目标。本文设计并实现一个面向普通话声调学习的可解释 AI 反馈系统：系统以短音频为输入，提取并归一化基频（F0）曲线，预测目标声调，并将学习者曲线与目标五度调值轮廓进行对比，生成面向学习者的规则化反馈。为验证模型路径，本文从 THCHS-30 / OpenSLR SLR18 转写文本中派生 syllable/短词级声调实验子集：声调标签来自 `.wav.trn` 中的拼音数字声调，边界由确定性近似切分获得，并通过时长、RMS 能量和 voiced-frame ratio 过滤。pilot 子集共 480 个切片，四声均衡。实验比较了传统声学特征、wav2vec2 冻结表征和二者融合三种分类方法；在测试集上，wav2vec2 表征取得最高结果（accuracy = 0.3125, macro-F1 = 0.3149），高于声学基线（accuracy = 0.2250, macro-F1 = 0.1983）和融合模型（accuracy = 0.2625, macro-F1 = 0.2599）。结果说明，预训练语音表征对派生声调分类有一定帮助，但自动切分边界、连续语流协同发音和非学习者语料限制了结果解释。本文贡献在于把声学语音学中的 F0 曲线、音系学中的调类/调值区分，以及预训练语音模型实验连接到一个可演示的学习反馈原型中。

**关键词：** 普通话声调；基频曲线；五度调值；预训练语音表征；可解释反馈

## 1 引言

普通话声调是用音高区别词义的典型超音段特征。对普通话学习者而言，声调困难并不只是“读成了几声”的分类问题，还包括音高起点、升降方向、转折位置和整体稳定性等连续声学控制问题。例如，一声要求相对稳定的高平轮廓，二声要求明显上升，三声常表现为低凹或转折，四声则要求快速下降。如果反馈只给出“正确/错误”或一个总分，学习者难以知道应当调整哪个声学维度。

语言科学课程中的声学语音学和音系学概念为这一问题提供了自然框架。声学语音学把语音视为可测量信号，F0 曲线可作为声调分析的重要线索；音系学则区分调类和调值，前者是语言系统中的类别，后者是具体音高实现。普通话四声可分别描述为阴平、阳平、上声、去声等调类，也可用赵元任五度标记法近似表示调值。语言习得视角进一步强调，学习者需要形成声调范畴，同时也需要通过反馈修正自己的产出轮廓。

与此同时，预训练语音模型为声调分类提供了新的计算路径。wav2vec2 等模型通过大规模无标注语音学习表征，可能捕捉到比少量手工声学特征更丰富的音段和超音段信息。课程中关于 wav2vec2 声调表征、声调范畴学习和模型可解释性的讨论表明，计算模型不仅可以作为工程工具，也可以作为语言科学研究中的分析对象。然而，面向学习者的系统不能只追求分类准确率，还需要把模型输出转化为可理解的语言学反馈。

本文围绕“预训练语音表征能否结合传统 F0 声学特征，为普通话声调学习提供可解释反馈”这一问题，构建一个小型混合项目。项目包括三个部分：第一，设计一个 Web 原型，使用户选择目标声调、上传或录制短音频，并获得预测、F0 曲线和反馈；第二，构建一个可复现实验数据流程，从公开 THCHS-30 语料的拼音转写中派生声调切片；第三，比较声学基线、预训练表征和融合模型，并把真实结果作为论文分析依据。

## 2 语言学背景

### 2.1 调类、调值与五度标记

声调语言使用音高差异区别词义。普通话通常分析为四个主要词汇声调：阴平、阳平、上声和去声。这里的“四声”首先是音系系统中的调类，即能够区别词义的类别；具体发音时，不同说话人、语境和语速会导致实际音高曲线变化，因此不能把单次 F0 曲线简单等同于调类本身。

调值用于描述调类的典型音高实现。赵元任五度标记法把相对音高分为 1 到 5 五个等级，可以把普通话一声近似描述为高平，二声描述为上升，三声描述为低凹或降升，四声描述为下降。本文系统的反馈设计正是建立在“调类—调值”区分上：模型预测提供调类判断，F0 可视化和目标曲线比较则帮助学习者理解自己的调值实现。

### 2.2 F0 轮廓与可解释反馈

F0 是声带振动周期对应的基频，是声调声学分析的重要指标。虽然 F0 会受到性别、年龄、个体嗓音范围和语境的影响，但归一化后的 F0 轮廓仍可用于比较音高运动方向和相对形状。本文原型将短音频中的 F0 估计结果映射到 1–5 的相对音高范围，并计算起点、中点、终点、范围、斜率、时长和有声帧比例等特征。

反馈规则不使用自由生成文本，而是与可观察声学属性绑定。例如，当目标为二声而终点相对起点上升不足时，系统提示“二声需要明显上升”；当目标为四声而下降幅度不足时，系统提示“四声需要明显下降”。这种设计可以避免模型给出难以解释的黑箱评价，也符合语言学习中“指出可操作偏差”的需求。

## 3 系统设计

系统采用前后端分离结构。前端使用 React 展示目标声调选择、录音/上传入口、反馈卡片和 F0 曲线图；后端使用 FastAPI 接收音频，完成音频读取、F0 提取、特征摘要、声调预测和反馈生成。离线实验脚本独立于 Web 服务运行，用于训练和评估模型，并生成论文结果。

完整数据流为：用户选择目标声调并上传或录制短音频；后端读取音频并估计 F0；F0 值被说话人内归一化到五度范围；模型给出预测声调与置信度；系统生成目标声调曲线，并将学习者曲线与目标曲线共同返回给前端；前端以图表和反馈列表展示结果。

第一版原型故意限制在孤立音节或短词层面，不支持完整 ASR、句子级评分、账户系统或长期学习记录。这一边界有助于保持项目与语言科学问题对齐：系统关注声调类别、调值轮廓和可解释反馈，而不是通用语音识别或产品化练习平台。

## 4 数据构建与实验方法

### 4.1 THCHS-30 派生声调切片

实验使用 THCHS-30 / OpenSLR SLR18 作为公开语音来源。需要强调的是，THCHS-30 原生并不提供人工切分的孤立音节声调标签。本文使用的是从转写文本派生的 syllable/短词级声调实验子集：每个 `.wav.trn` 文件包含中文文本、带数字声调的拼音行和音素行；脚本从拼音数字中提取 1–4 声标签，排除轻声和非声调 token，并按转写顺序对整句音频进行确定性近似切分。

切片生成过程包括：读取 split 中的 wav 与 `.trn` 引用文件；解析真实 `.wav.trn`；按原始拼音 token 序列生成时间槽位，其中轻声或非 tonal token 保留其时间位置但不输出为训练样本；对候选切片应用时长、RMS 能量和 voiced-frame ratio 过滤；按 split 与 tone quota 写出 wav 切片与 metadata。metadata 字段包括 `audio_path,text,pinyin,tone,speaker_id,split,source_utterance,start_sec,end_sec,source_dataset,label_method`，从而保留来源与切分方法。

pilot 设置为 train 每声最多 80 个、val 每声 20 个、test 每声 20 个。最终得到 480 个切片，四声均衡：训练集 320 个，验证集 80 个，测试集 80 个。该数据适合作为课程项目中的可复现 public-data baseline，但不能被描述为人工标注的孤立音节声调语料。

### 4.2 三类模型

声学基线使用可解释特征：归一化 F0 起点、中点、终点、范围、斜率、时长和 voiced ratio，并训练随机森林分类器。该路径直接对应声学语音学中的 F0 轮廓分析，也是学习者反馈规则的可解释基础。

预训练表征模型使用 `facebook/wav2vec2-base` 冻结编码器。脚本将切片音频重采样到 16 kHz，输入 wav2vec2，取最后隐藏层的 mean pooling 作为 utterance-level representation，再用 logistic regression 分类四个声调。由于服务器无法稳定访问 Hugging Face，本文先在本地下载模型缓存并同步到 `/NAS/yesh/hf_cache`，随后在服务器上以离线模式运行实验。

融合模型将声学特征与 wav2vec2 表征按行拼接，再训练 logistic regression 分类器。融合路线的假设是：预训练表征捕捉更丰富的语音信息，而 F0 特征显式提供声调相关音高运动信息。

## 5 实验结果

表 1 和 `paper/figures/confusion_matrices_thchs_slices_pilot.png` 给出 pilot 测试集上的三类模型结果。所有数值均来自服务器输出文件 `outputs/thchs_slices_pilot/*/*_metrics.json`，不是人工估计或占位数字。

| 模型 | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| 声学特征基线 | 0.2250 | 0.1983 |
| wav2vec2 冻结表征 | 0.3125 | 0.3149 |
| 声学 + wav2vec2 融合 | 0.2625 | 0.2599 |

在该派生 pilot 子集上，wav2vec2 冻结表征优于声学基线，说明预训练语音表征确实捕捉到一部分与声调分类相关的信息。声学基线结果较低，可能与自动切分边界不精确、连续语流中声调受上下文影响、以及只使用简单 F0 摘要有关。融合模型没有超过单独的 wav2vec2 表征，提示当前简单拼接和线性分类器没有有效利用两类特征，也可能受到小样本规模和切片噪声影响。

表征可视化结果见 `paper/figures/representation_tsne_thchs_slices_pilot.png`，四声 F0 示例见 `paper/figures/f0_examples_thchs_slices_pilot.png`。这些图用于探索 wav2vec2 表征中的声调可分性和派生切片中的 F0 形状，而不是作为强因果证据。由于 pilot 数据来自连续语音近似切片，点云混合并不意味着模型完全无法学习声调，也可能反映边界误差、协同发音和句调影响。

## 6 反馈示例与语言科学意义

系统的学习者反馈并不直接复述模型分类结果，而是把预测与 F0 曲线结合。例如，对于目标二声，若学习者曲线从起点到终点的上升幅度不足，系统生成“二声需要明显上升，你的上升幅度不足”；对于目标四声，若起点到终点下降不足，则生成“四声需要明显下降，你的下降幅度不足”。这些反馈对应的是可观察的 F0 运动，而不是抽象的“发音不好”。

从语言科学角度看，该系统把多个课程概念连接起来。第一，它使用声学语音学方法测量 F0、时长和有声帧比例。第二，它使用音系学中的调类概念组织四声分类，同时用五度调值解释具体音高形状。第三，它回应语言习得中的范畴学习问题：学习者需要从连续声学输入中形成离散声调类别，并通过反馈调整产出。第四，它把 wav2vec2 等预训练语音模型作为计算语言科学工具，用真实语音表征实验支持系统设计。

## 7 局限与结论

本文有三个主要局限。第一，实验数据是从 THCHS-30 转写文本派生的切片，而不是人工切分的孤立音节声调语料；边界由确定性近似方法得到，可能引入标签与音频不完全对齐的问题。第二，THCHS-30 是普通话连续朗读语料，并非二语学习者发音语料，因此实验结果不能直接解释为学习者纠错有效性。第三，当前模型只比较了简单声学特征、冻结 wav2vec2 表征和简单融合分类器，尚未进行更强的 fine-tuning、上下文控制或人工听辨验证。

尽管如此，本文展示了一个可复现、可演示的混合型语言科学项目：通过 F0 曲线和五度调值将声调反馈解释给学习者，通过公开语料派生实验子集比较不同模型路线，并通过 Web 原型把声学分析、模型预测和反馈可视化连接起来。结果表明，在当前 pilot 设置下，预训练语音表征优于传统声学摘要特征，但整体性能仍受到数据构建和切片质量限制。未来工作可使用人工对齐或更适合声调研究的孤立音节/学习者语料，加入混淆矩阵可视化和人工评价，并探索更稳健的表征融合方法。
